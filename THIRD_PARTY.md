# Third-Party Components

This repository does not vendor third-party models or checkpoints.

- Molmo model code and weights: https://github.com/allenai/molmo and https://huggingface.co/allenai
- Recommended Molmo checkpoint for the lightweight frontend adapter: https://huggingface.co/allenai/Molmo-7B-D-0924
- M2T2-style candidate generation should be installed separately if used for real 6-DoF grasp candidates.

Check each upstream license before redistributing checkpoints or derived assets.
